The weight-space section

θ(a, b) = θ₀ + a u + b v

The vectors u and v are fixed orthonormal directions in weight space. The original section passes through three independently SGD-trained spiral classifiers. Each nearby point gives another set of weights for the same network architecture.

| L(θ) / L(θ₀) − 1 | ≤ 0.01

Every colored model satisfies this common training-loss band. The gray surface is measured training cross-entropy. The three enlargements preserve the section's coordinate directions and equal axis units.

Neuron alignment permutes hidden units while preserving each SGD function, giving a second affine section. The color range for each metric is shared across all three neighborhoods and both sections.

Each section contains 1,536 sampled alternatives and the three SGD references. Behavioral metrics use fixed held-out inputs. Spectral and rank metrics describe weight matrices or hidden activations, as named in the selector.
